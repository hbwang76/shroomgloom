# Shroom and Gloom Guide

Static Next.js frontend for the Shroom and Gloom fan guide. The current MVP renders only handoff example records from `src/data/cards.ts`; expand that data only with the hand-verified upstream bundle.

## Run

```bash
npm install
npm run build
npm run dev
```

Routes: `/`, `/tier-list/`, `/best-builds/`, `/characters/`, `/beginner-guide/`, `/quests/`, `/patch-notes/`, `/cards/[slug]/`, plus legal pages.

Canonical: https://shroomgloom.online
